# Wearable Devices Specification Helper

The **Wearable Devices Specification Helper** is a web-based Shiny tool for creating standardized specification sheets for wearable light loggers and optical radiation dosimeters. It helps users collect key metadata (hardware, software, measurement, and practical deployment details) in one place and export a structured report.

## Who is this for?

This tool is designed for:

- Researchers and lab teams working with wearable light-measurement devices.
- Study coordinators preparing procurement and protocol-ready device documentation.
